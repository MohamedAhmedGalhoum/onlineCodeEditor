**Online Web Code Editor & Playground**

Developed a browser-based interactive coding environment that allows users to write, run, test, save, and load HTML, CSS, and JavaScript projects directly in the browser.

**Key Features:**

* Integrated ACE Editor with dedicated HTML, CSS, and JavaScript editing environments.
* Implemented live web preview using browser-based `iframe`/`srcdoc` execution.
* Added JavaScript execution and custom test support for web projects.
* Implemented project persistence using Local Storage.
* Added JSON-based project export and import functionality.
* Built keyboard shortcuts for running and saving projects.
* Implemented dynamic console-style logging with error and warning states.
* Added accessible editor tabs with keyboard navigation and ARIA attributes.
* Implemented HTML escaping to safely display console messages.
* Designed a flexible project format supporting different versions and legacy project structures.

**Technologies:** JavaScript (ES6+), HTML5, CSS3, DOM APIs, ACE Editor, Local Storage, JSON, Browser APIs.
